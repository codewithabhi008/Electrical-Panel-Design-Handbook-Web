SLD – Single Line Diagram

Power Distribution Representation

1. Introduction

SLD stands for Single Line Diagram. It represents an electrical power distribution system using simplified single-line symbols.

2. Common Elements

  • Power sources
  • Transformers
  • ACBs and MCCBs
  • Busbars
  • Feeders
  • Generators
  • Changeover systems
  • Loads

3. Basic Example

UTILITY
   ↓
ACB INCOMER
   ↓
MAIN BUSBAR
   ↓
MCCB OUTGOINGS
   ↓
LOADS

4. Information to Identify

  • Source and voltage
  • Transformer rating
  • Breaker ratings
  • Cable / busbar
  • Load
  • Protection
  • Metering
  • Earthing
  • Changeover arrangement
