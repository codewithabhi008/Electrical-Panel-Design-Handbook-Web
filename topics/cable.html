Cable Selection Basics

Current • Voltage Drop • Installation

1. Selection Factors

  • Load current
  • Voltage
  • Installation method
  • Ambient temperature
  • Cable grouping
  • Voltage drop
  • Short-circuit withstand
  • Insulation
  • Number of cores
  • Length

2. Basic Consideration

Load Current ≤ Cable Permissible Current

The cable must also satisfy applicable voltage-drop and short-circuit requirements.

3. Voltage Drop

Consider cable length, load current, cable impedance, power factor and system voltage. Permissible voltage drop depends on the applicable standard and project requirements.
