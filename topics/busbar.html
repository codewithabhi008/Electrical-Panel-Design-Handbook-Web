Busbar Selection Basics

Copper • Aluminium • Withstand

1. Introduction

A busbar is a conductive metallic bar used for power distribution inside a panel. Common materials are copper and aluminium.

2. Types

  • Main busbar
  • Vertical busbar
  • Horizontal busbar
  • Neutral busbar
  • Earth busbar
  • Distribution busbar

3. Selection Factors

  • Rated current
  • Short-circuit withstand
  • Temperature rise
  • Material
  • Cross-section
  • Support spacing
  • Insulation
  • Installation arrangement

4. Current Density

CURRENT DENSITY = CURRENT / CROSS-SECTIONAL AREA

This can be used as a preliminary design consideration. Final sizing should be verified using applicable standards, temperature-rise requirements and short-circuit withstand requirements.
