TECHNICAL REFERENCE

Changeover Systems

Manual & Automatic Changeover

1. Introduction

A changeover system transfers an electrical load from one power source to another.

2. Types

  • Manual changeover
  • Electrical changeover
  • Automatic changeover
  • Mains-to-Mains
  • Mains-to-DG
  • Transformer-to-Transformer
  • Two-incomer / bus-coupler arrangements
  • Motorized breaker changeover

3. Basic Arrangement

SOURCE-1 → BREAKER-1 → LOAD
SOURCE-2 → BREAKER-2 → LOAD

4. Mains-to-DG Sequence

MAINS FAILURE
      ↓
DG START COMMAND
      ↓
DG HEALTHY
      ↓
MAINS BREAKER OFF
      ↓
DG BREAKER ON
      ↓
LOAD ON DG

5. Return to Mains

After mains becomes healthy for the required return delay, the DG breaker is opened and the mains breaker is closed according to the approved control sequence.

6. Open Transition

Break-before-make: first source OFF, then second source ON.

7. Closed Transition

Controlled temporary parallel operation requires suitable synchronization, protection, paralleling controls and interlocking.

For a normal non-parallel system, the two source breakers must be appropriately interlocked to prevent unintended simultaneous connection.
