BOM & BOQ

Project Documentation

1. BOM

BOM stands for Bill of Materials. It lists components and materials required for manufacturing a panel.

Typical Fields

  • Item number
  • Description
  • Manufacturer
  • Part number
  • Quantity
  • Rating
  • Remarks

2. BOQ

BOQ stands for Bill of Quantities. It is commonly used for project quantities and commercial estimation.

Typical Fields

  • Item description
  • Quantity
  • Unit
  • Rate
  • Amount
  • Specification
  • Remarks
