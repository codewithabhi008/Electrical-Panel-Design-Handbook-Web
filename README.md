# ⚡ Electrical Panel Design Handbook

A GitHub Pages-ready technical documentation website for electrical panel design topics.

## Features

- Responsive documentation layout
- Dark / light mode
- Topic search on homepage
- Sidebar navigation
- Previous / Next topic navigation
- Clean engineering-documentation UI
- Pure HTML, CSS and JavaScript
- No frameworks or build tools required

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a public repository.
2. Upload all files and folders while keeping the structure unchanged.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for deployment.
